# Driver Drowsiness & Fatigue Detection System

A real time computer vision application built with **Python** and **OpenCV** to monitor driver alertness and trigger audio alerts when eyes remain closed.

---

## Features
* **Real time Face & Eye Detection:** Uses OpenCV Haar Cascade Classifiers to detect facial features frame-by-frame.
* **Audio Warning System:** Triggers system sound alerts when closed/unmonitored eyes are detected across consecutive frames.
* **Live Performance Overlay:** Displays current FPS and driver alertness status in real time.
* **Lightweight Execution:** Designed to run smoothly on standard CPUs without requiring GPU acceleration.

---

## Built With
* **Python 3.x**
* **OpenCV (`opencv-python`)**
* **NumPy**

---
