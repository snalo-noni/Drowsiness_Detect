# Driver Drowsiness & Fatigue Detection System

A real-time computer vision application built with **Python** and **OpenCV** to monitor driver alertness and trigger audio alerts when signs of drowsiness are detected.

---

## Purpose

The purpose of this project is to improve road safety by detecting early signs of driver fatigue and drowsiness. Driver fatigue is one of the leading causes of road accidents, particularly during long-distance travel and late-night driving. This system continuously monitors the driver's eyes using computer vision techniques and issues an alert when prolonged eye closure is detected.

By providing timely warnings, the application helps drivers regain focus and reduce the risk of accidents caused by fatigue.

---

## Features

* **Real-Time Face & Eye Detection:** Uses OpenCV Haar Cascade Classifiers to detect facial features frame-by-frame.
* **Audio Warning System:** Triggers system sound alerts when closed or unmonitored eyes are detected across consecutive frames.
* **Live Performance Overlay:** Displays current FPS and driver alertness status in real time.
* **Lightweight Execution:** Designed to run smoothly on standard CPUs without requiring GPU acceleration.

---

## How It Helps
